# 🏥 Hospital Management System in C

A console-based Hospital Management System developed in C using Linked Lists and File Handling.

## ✨ Features

- Create Patient Account
- Book Appointment
- Search Patient
- Print Patient Details
- Modify Patient Details
- Delete Patient
- Automatic Data Saving
- Automatic Data Loading

## 🛠 Technologies Used

- C Programming
- Linked Lists
- File Handling
- GCC
- Linux (Ubuntu)

## 📁 Project Structure

```
Hospital-Management-System-C/
│── main.c
│── hospital.h
│── create_account.c
│── book_appointment.c
│── print.c
│── search.c
│── modify.c
│── delete.c
│── save.c
│── load.c
│── return_menu.c
```

## ▶️ Compile

```bash
gcc *.c -o hospital
```

## ▶️ Run

```bash
./hospital
```
